MPL-2.0 ist eine Datei-basierte Copyleft-Lizenz: Änderungen **an mediabunny-Dateien selbst** müssen
unter MPL-2.0 veröffentlicht werden, das eigene Projekt drumherum bleibt unberührt. Unkritisch,
solange die Library nur benutzt und nicht gepatcht wird.

**Wenn doch gepatcht wird:** den Patch in einer separaten Datei halten und als MPL-2.0 kennzeichnen,
statt ihn in eigenen Code zu vermischen.
